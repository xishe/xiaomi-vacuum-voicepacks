# Установка и сборка через Mindsolo

[Mindsolo](https://vacuum.mindsolo.net/) предлагает загрузку готовых пакетов и конструктор отдельных фраз. Доступность зависит от модели и настроек аккаунта. Формат для загрузки подсказывает интерфейс выбранного устройства. [Описание загрузки своего пакета](https://vacuum.mindsolo.net/en/changelog/2022-10-08).

## Установить готовый ZIP

1. Войдите на сайт и откройте свой робот в списке устройств. Для Xiaomi воспользуйтесь подключением Xiaomi Home.
2. Сверьте точный идентификатор модели. Пакет из этого репозитория предназначен для **`ijai.vacuum.v19`**.
3. В разделе озвучек устройства откройте загрузку своего пакета, если она доступна. Укажите [ZIP 1.0](../packs/ijai.vacuum.v19/witcher3-ru-ijai-v19-v1.0.zip) целиком. Для другой модели используйте пакет, собранный именно для неё.
4. Поставьте робот на базу и запустите установку из интерфейса сайта. Проверьте голос командой «Найти робот».

## Перенести отдельные фразы на другую модель

1. В [конструкторе Mindsolo](https://vacuum.mindsolo.net/create/voicepack) выберите точную модель. Работайте со списком событий, который показан для неё.
2. Извлеките записи из ZIP командой `python voicepack.py extract` по [инструкции репозитория](../README.md#сборка-своего-пакета). Для каждого нужного события найдите соответствующую запись по смыслу. [Карта исходных событий Mop 2S](../packs/ijai.vacuum.v19/PHRASES.md).
3. У нужной фразы выберите загрузку файла. Прослушайте запись, при необходимости подрежьте её или поправьте громкость и сохраните.
4. Просмотрите заполненные события. Соберите пакет для выбранной модели и установите его через сайт.

Так можно перенести аудиозаписи между моделями с разными именами файлов или форматами. Шаги приведены по документации Mindsolo. На реальном Mop 2S проверен способ установки через локальный MIoT. [Руководство конструктора Mindsolo](https://vacuum.mindsolo.net/info/create-voicepack).
