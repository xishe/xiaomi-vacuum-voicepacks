# Совместимость

Название на коробке может быть одинаковым у устройств с разными кодами модели. Для выбора пакета используйте идентификатор вида `ijai.vacuum.v19` из своего устройства. Команда `python install.py --ip 192.168.1.50 --status` выводит модель, которую сообщил сам робот. Подставьте свой локальный IP.

| Модель | Локальная установка | Где взять звуки |
| --- | --- | --- |
| **`ijai.vacuum.v19`**, Xiaomi Robot Vacuum-Mop 2S | Проверено на прошивке `4.3.3_0081` | [Готовый V4.1](../packs/ijai.vacuum.v19/mop-2s-witcher-v4.1-v19.zip) или свой ZIP, собранный из заводского шаблона |
| `ijai.vacuum.v3`, Xiaomi Mi Robot Vacuum-Mop 2 Pro | Экспериментально, команды сверены со спецификацией MIoT | Свой ZIP и заводской шаблон v3 |
| `ijai.vacuum.v17` | Экспериментально, команды сверены со спецификацией MIoT | Свой ZIP и заводской шаблон v17 |
| `ijai.vacuum.v18` | Экспериментально, команды сверены со спецификацией MIoT | Свой ZIP и заводской шаблон v18 |
| Другие модели с ZIP MP3 + `md5.ini` | Проверка и сборка офлайн, установка доступным для модели способом | Заводской шаблон именно этой модели |
| Устройства с другими форматами | Подбор отдельных фраз в [конструкторе Mindsolo](mindsolo.md), если модель есть в каталоге | Записи из своего источника или отдельные MP3 из пакета |

## Как выбрать шаблон

- Используйте заводской голосовой пакет для своего идентификатора модели. Для сверки в репозитории использовался [заводской русский ZIP для v19](https://cdn.awsde0.fds.api.mi-img.com/ijai-2s-map.record/AudioOTA/ru_RU.zip). Для v3 см. [репозиторий Q0/ijai.vacuum](https://github.com/Q0/ijai.vacuum).
- Сверяйте набор имён файлов и параметры MP3 с шаблоном. Для переноса между моделями сопоставляйте события по смыслу. Номер в начале файла может означать разные события на разных роботах.
- Перед установкой своего пакета выполните `python voicepack.py inspect custom.zip --template stock.zip`. Инструмент проверяет структуру ZIP, набор дорожек, параметры MP3 и контрольные суммы. Для v19 можно добавить `--model ijai.vacuum.v19`, чтобы использовать проверенные для V4.1 MP3 48 кГц моно даже там, где заводская озвучка использует другие параметры.

## Что проверено для локальной установки

Во всех четырёх профилях Xiaomi MIoT публикует сервис `language` (`14`), загрузку озвучки (`14/1` с входами `1, 5, 6`) и чтение статуса (`14/2`). Скрипт требует совпадения точной модели и использует загруженный по локальному HTTP пакет. Совпадение команд MIoT подтверждает профиль протокола. Поведение прошивки и формат пакета зависят от модели.

[Спецификация v3](https://miot-spec.org/miot-spec-v2/instance?type=urn%3Amiot-spec-v2%3Adevice%3Avacuum%3A0000A006%3Aijai-v3%3A1) · [спецификация v17](https://miot-spec.org/miot-spec-v2/instance?type=urn%3Amiot-spec-v2%3Adevice%3Avacuum%3A0000A006%3Aijai-v17%3A1) · [спецификация v18](https://miot-spec.org/miot-spec-v2/instance?type=urn%3Amiot-spec-v2%3Adevice%3Avacuum%3A0000A006%3Aijai-v18%3A1) · [спецификация v19](https://miot-spec.org/miot-spec-v2/instance?type=urn%3Amiot-spec-v2%3Adevice%3Avacuum%3A0000A006%3Aijai-v19%3A1)

Если проверяете другой робот, в Issue укажите точную модель, прошивку, формат заводского пакета и результат установки. В сообщении достаточно этих данных. Токен, IP, идентификаторы устройств и данные аккаунта храните у себя.
