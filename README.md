# Xiaomi Vacuum Voicepacks

Инструменты для проверки и сборки голосовых ZIP-пакетов и локальной установки на модели Xiaomi/ijai с подходящим профилем MIoT.

**«Ведьмак 3 RU · Mop 2S» 1.0** содержит 108 звуков. Реплики на русском, встречается ненормативная лексика. Локальная установка проверена на **Xiaomi Robot Vacuum-Mop 2S (`ijai.vacuum.v19`)** с прошивкой **`4.3.3_0081`**.

Фанатский контент для личного использования. Права на игровые материалы принадлежат их правообладателям.

| Задача | Что использовать |
| --- | --- |
| Установить озвучку на Mop 2S | [Скачать «Ведьмак 3 RU» 1.0](packs/ijai.vacuum.v19/witcher3-ru-ijai-v19-v1.0.zip) · [карта реплик по событиям](packs/ijai.vacuum.v19/PHRASES.md) |
| Установить ZIP или собрать озвучку на сайте | [Инструкция Mindsolo](docs/mindsolo.md) |

## Подготовка Python

Понадобится Python 3.10 или новее. Выполняйте команды из корня репозитория.

**Windows PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**macOS и Linux**

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

В командах ниже `python` означает Python из этого окружения. В Windows можно подставить `.\.venv\Scripts\python.exe`, в macOS и Linux — `.venv/bin/python`.

## Сборка своего пакета

Возьмите **заводской ZIP для точной модели**. Инструмент работает со структурой, в которой MP3 и `md5.ini` лежат в корне. Для остальных форматов смотрите [варианты установки по моделям](docs/compatibility.md).

1. Посмотрите имена дорожек, частоту дискретизации и число каналов:

   ```sh
   python voicepack.py inspect stock.zip --list
   ```

2. Положите в папку `clips` только MP3, которые хотите заменить. Имя и параметры каждой дорожки должны совпадать с заводским файлом. Для готового пакета Mop 2S ориентируйтесь на [карту событий](packs/ijai.vacuum.v19/PHRASES.md).

3. Соберите свой ZIP и проверьте его по тому же шаблону:

   ```sh
   python voicepack.py build stock.zip clips custom.zip
   python voicepack.py inspect custom.zip --template stock.zip
   ```

Сборщик пересчитывает `md5.ini`, сохраняет остальные заводские дорожки и показывает разницу в размере. Для Mop 2S у команд `build` и `inspect` есть параметр `--model ijai.vacuum.v19`. Он также разрешает проверенный на v19 формат MP3 48 кГц моно. Ограничения памяти зависят от модели. Если пакет заметно больше оригинала, укоротите фразы или уменьшите размер аудио с сохранением параметров модели.

Чтобы послушать отдельные звуки или использовать их в конструкторе Mindsolo, извлеките MP3 в новую папку:

```sh
python voicepack.py extract packs/ijai.vacuum.v19/witcher3-ru-ijai-v19-v1.0.zip extracted
```

## Установка по локальной сети

Подключите компьютер и робот к одной сети, поставьте робот на базу и найдите его локальный IPv4. Требуется 32-символьный miIO-токен именно этого робота. Установщик запрашивает его скрыто. Способ получения зависит от модели и аккаунта. [Документация python-miio по токенам](https://python-miio.readthedocs.io/en/latest/discovery.html#obtaining-tokens).

**Готовый пакет 1.0 для Mop 2S**

```sh
python install.py --check
python install.py --ip 192.168.1.50 --status
python install.py --ip 192.168.1.50
```

`192.168.1.50` приведён для примера. Подставьте адрес своего робота. **Свой пакет** устанавливается с указанием модели и заводского шаблона:

```sh
python install.py --ip 192.168.1.50 --model ijai.vacuum.v19 --package custom.zip --template stock.zip
```

Для другой модели подставьте её точный идентификатор из [таблицы профилей](docs/compatibility.md). Установщик сверяет его с ответом устройства. По умолчанию выбирается `ru_RU`, а если этот слот уже активен — `fr_FR`. Слот можно задать через `--locale ru_RU` или `--locale fr_FR`. В последнем случае приложение может показать французский язык, хотя в пакете русские дорожки.

Робот скачивает ZIP с временного HTTP-сервера на компьютере. Дождитесь сообщения **«Голосовой пакет активен»**, затем выполните «Найти робот» в Xiaomi Home, чтобы проверить динамик.

### Если возникла ошибка

| Симптом | Что проверить |
| --- | --- |
| Статус устройства не читается | Локальный IP, токен и доступ по UDP 54321. |
| Робот не получил ZIP | Изоляцию клиентов в роутере, VPN и брандмауэр компьютера. Для Python может понадобиться разрешение на входящие подключения в частной сети. |
| ZIP передан, активация ещё не подтверждена | Прочитайте состояние через `--status` и дождитесь окончания текущей загрузки. |
| Пакет активен, робот молчит | Громкость и расписание режима «Не беспокоить» в Xiaomi Home. |

Для возврата стандартного голоса выберите официальный пакет в настройках робота в Xiaomi Home.

- Русский игровой дубляж **The Witcher 3: Wild Hunt**, CD PROJEKT RED. Для подбора использовались [WitchSpeech](https://huggingface.co/datasets/korovsky/witchspeech) и [аудиоархив Rootreck](https://huggingface.co/datasets/Rootreck/so-vits-svc-4.0-ru-The_Witcher_3_Wild_Hunt).
- Короткий сигнал `sound_beep_beep.mp3` взят из штатного пакета Xiaomi.
- Описание совместимости опирается на спецификации Xiaomi MIoT, [проект Q0/ijai.vacuum](https://github.com/Q0/ijai.vacuum) и [документацию Mindsolo](https://vacuum.mindsolo.net/info/create-voicepack).
